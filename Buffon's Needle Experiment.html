Buffon's Needle Experiment

An advanced interactive simulation demonstrating how randomized geometric vectors converge organically to calculate the value of Pi (π).

The Mathematical Formula Breakdown

When an object of uniform length is tossed completely at random onto a grid of parallel lines, the intersection criteria relies on circle properties and trigonometry:

Probability (P) =
2 × L
D × π

Variable Matrix:

  • P Probability of Intersection: The ratio of hits defined by the formula C ÷ N.
  • C Line Crosses: The total number of needles that physically intersect or cross any grid line.
  • N Total Drops: The cumulative number of needles randomly dropped onto the field.
  • L Needle Length: Input vector length in pixels.
  • D Line Spacing: Width between the parallel floorboard lines.
  • π Isolated Pi value: Formulated using inverse probabilities:
    π = (2 × L × N) / (D × C)
